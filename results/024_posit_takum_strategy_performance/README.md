# Scalar posit and takum strategy results

Timestamped smoke and full runs for the experiment specified in
`docs/posit_takum_strategy_benchmark.md` are stored here. Slurm output files
stay at this level so a failed job can be diagnosed without guessing which run
directory it created.

The finished results are presented in the
[HTML report](../report/posit-takum.html). The generated
[Markdown companion](summary.md) contains the complete case tables in a
plain-text format.
