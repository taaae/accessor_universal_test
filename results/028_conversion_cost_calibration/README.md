# Experiment 028: fixed H200 conversion-cost calibration

This directory receives immutable smoke/full/profile runs for the 112-case
synthetic training inventory, 12 synthetic validation cases, five real
development converters, and six untouched real final converters. The fixed
target is a scalar x1 FP64 DOT over two uint32 streams at N=2^27 on one
non-student H200 NVL.
