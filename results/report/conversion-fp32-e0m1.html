Best strategies explained

DOT Dense x1

dense/scalar/x1/fixed_integer

Reads the compact 2-bit bitstream without padding. Each thread loads and decodes one value at a time. Treats the exponent-free payload as a signed fixed-point integer and applies its compile-time power-of-two scale.

dense 2-bit stream → scalar x1 → Fixed-point integer path → FP32 FMA

DOT Padded x1

padded/scalar/x1/fixed_integer

Reads one 8-bit slot per value; 6 padding bits are unused. Each thread loads and decodes one value at a time. Treats the exponent-free payload as a signed fixed-point integer and applies its compile-time power-of-two scale.

padded 8-bit slots → scalar x1 → Fixed-point integer path → FP32 FMA

DOT Dense Best

dense/thread_packet/x8/full_lut_shared

Reads the compact 2-bit bitstream without padding. Each thread loads one packet containing 8 adjacent values and processes all decoded lanes. Uses the 2-bit code as an index into a 4-entry table holding the final arithmetic value. The table is staged in shared memory.

dense 2-bit stream → thread packet x8 → Full lookup · shared memory → FP32 FMA

GEMV Dense Best

dense/cooperative_shuffle/x16/full_lut_shared

Reads the compact 2-bit bitstream without padding. A cooperative group loads a dense 16-value chunk as 1 × 32-bit words, redistributes them with warp shuffles, and gives each of 4 consumer lanes 4 values to decode. Uses the 2-bit code as an index into a 4-entry table holding the final arithmetic value. The table is staged in shared memory.

dense 2-bit stream → shuffle chunk x16 → Full lookup · shared memory → FP32 FMA
