Why results are not 100% trustworthy

Best strategy measured here: padded/thread_packet/x8/full_lut_shared.

100.0% of U(0,1) and 68.3% of N(0,1) fall below this format's smallest normal value, so the benchmark stores data the format can barely represent. The winning strategy is value independent, so the timings themselves stand, but they describe a format being used outside its range and should not be read as a recommendation.

Best strategies explained

DOT x1

padded/scalar/x1/full_lut_shared

Reads one 8-bit slot per value; 3 padding bits are unused. Each thread loads and decodes one value at a time. Uses the 5-bit code as an index into a 32-entry table holding the final arithmetic value. The table is staged in shared memory.

padded 8-bit slots → scalar x1 → Full lookup · shared memory → FP64 FMA

DOT Best

padded/thread_packet/x8/full_lut_shared

Reads one 8-bit slot per value; 3 padding bits are unused. Each thread loads one packet containing 8 adjacent values and processes all decoded lanes. Uses the 5-bit code as an index into a 32-entry table holding the final arithmetic value. The table is staged in shared memory.

padded 8-bit slots → thread packet x8 → Full lookup · shared memory → FP64 FMA
