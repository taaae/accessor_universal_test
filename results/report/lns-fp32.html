What these formats are

An LNS<B,R> value stores one sign bit and a signed B-1 bit fixed-point logarithm with R fractional bits. The integer part I = B-1-R sets dynamic range and R sets relative precision, so every format has an exact IEEE counterpart E<I>M<R> named on its page.

Fused multiplication adds the two stored logarithms as widened integers and decodes only the product, replacing two decodes with one.
