Best strategies explained

DOT x1

padded/scalar/x1/direct_branchy

Reads one 32-bit slot per value; 15 padding bits are unused. Each thread loads and decodes one value at a time. Extracts sign, exponent, and mantissa fields and constructs the target floating-point value directly, with separate zero/subnormal/normal paths.

padded 32-bit slots → scalar x1 → Direct bit construction · branchy → FP64 FMA

DOT Best

padded/thread_packet/x8/direct_branchy

Reads one 32-bit slot per value; 15 padding bits are unused. Each thread loads one packet containing 8 adjacent values and processes all decoded lanes. Extracts sign, exponent, and mantissa fields and constructs the target floating-point value directly, with separate zero/subnormal/normal paths.

padded 32-bit slots → thread packet x8 → Direct bit construction · branchy → FP64 FMA

GEMV x1

padded/scalar/x1/prefix_lut_shared

Reads one 32-bit slot per value; 15 padding bits are unused. Each thread loads and decodes one value at a time. Looks up the sign and exponent prefix in a 64-entry table and inserts the 11 stored mantissa bits directly, falling back to direct construction for zero-exponent and special codes. The table is staged in shared memory.

padded 32-bit slots → scalar x1 → Prefix lookup · shared memory → FP64 FMA

GEMV Best

padded/thread_packet/x8/direct_branchy

Reads one 32-bit slot per value; 15 padding bits are unused. Each thread loads one packet containing 8 adjacent values and processes all decoded lanes. Extracts sign, exponent, and mantissa fields and constructs the target floating-point value directly, with separate zero/subnormal/normal paths.

padded 32-bit slots → thread packet x8 → Direct bit construction · branchy → FP64 FMA
