Is it better than similar IEEE?

LNS<8,2> spends its 8 bits as one sign bit, 5 integer and 2 fractional logarithm bits, so its range and resolution match E5M2 aka FP8.

Best strategies explained

DOT x1

ordinary/padded/scalar/x1/full_lut_shared

Reads the compact 8-bit bitstream without padding. Each thread loads and decodes one value at a time. Uses the whole 8-bit code as an index into a 256-entry table holding the final value, so no exponential is evaluated. Both operands are decoded to the arithmetic type first and then multiplied normally.

dense 8-bit stream → scalar x1 → Full lookup · shared memory → 2 decodes → multiply → FP32 accumulate

DOT Best

ordinary/padded/thread_packet/x8/full_lut_shared

Reads the compact 8-bit bitstream without padding. Each thread loads one packet of 8 adjacent values and processes every decoded lane. Uses the whole 8-bit code as an index into a 256-entry table holding the final value, so no exponential is evaluated. Both operands are decoded to the arithmetic type first and then multiplied normally.

dense 8-bit stream → thread packet x8 → Full lookup · shared memory → 2 decodes → multiply → FP32 accumulate
