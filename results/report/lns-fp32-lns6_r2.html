Best strategies explained

DOT x1

ordinary/padded/scalar/x1/full_lut_shared

Reads one 8-bit slot per value; 2 padding bits are unused. Each thread loads and decodes one value at a time. Uses the whole 6-bit code as an index into a 64-entry table holding the final value, so no exponential is evaluated. Both operands are decoded to the arithmetic type first and then multiplied normally.

padded 8-bit slots → scalar x1 → Full lookup · shared memory → 2 decodes → multiply → FP32 accumulate

DOT Best

fused/padded/thread_packet/x8/pair_lut_shared

Reads one 8-bit slot per value; 2 padding bits are unused. Each thread loads one packet of 8 adjacent values and processes every decoded lane. Indexes a 4,096-entry table with both 6-bit codes at once, returning the finished product directly from shared memory. The two stored logarithms are added as widened integers, so the product is formed before any conversion and only the result is decoded — one decode per product instead of two.

padded 8-bit slots → thread packet x8 → Pair-product lookup · shared memory → fused log-add → 1 decode → FP32 accumulate
