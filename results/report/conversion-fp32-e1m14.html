Why results are not 100% trustworthy

Best strategy measured here: padded/thread_packet/x8/e1_integer.

100.0% of U(0,1) and 95.4% of N(0,1) fall below this format's smallest normal value, so the benchmark stores data the format can barely represent. The winning strategy is value independent, so the timings themselves stand, but they describe a format being used outside its range and should not be read as a recommendation.

Best strategies explained

DOT x1

padded/scalar/x1/e1_integer

Reads one 16-bit slot per value; the value fills the slot exactly. Each thread loads and decodes one value at a time. Uses the E1 layout's integer-like representation and an exact power-of-two scale instead of a general floating-point decoder.

padded 16-bit slots → scalar x1 → E1 integer path → FP32 FMA
