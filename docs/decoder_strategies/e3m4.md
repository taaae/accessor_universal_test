# E3M4 strategy decision

E3M4 already has the dedicated 42-strategy E2/E3 implementation and H200
study: generic, FP32/FP64/high-word/prefix LUTs, global/shared placements,
direct branchy/masked words, subnormal hybrids, bank-swizzled tables, and all
x1/x2/x4/x8 packet widths.

This pass adds:

- a 65,536-entry, 512 KiB global/L2 pair table returning two FP64 high words
  per lookup, tested at x4/x8;
- byte-permute extraction for direct branchy x4/x8 packets.

Only 25% of U(0,1) and about 19.74% of N(0,1) use source subnormals, so E3M4
has a more regular arithmetic decoder than E2M5. The pair table remains an
experiment because each lookup introduces random L2 traffic. All 256 codes are
exhaustively validated.
