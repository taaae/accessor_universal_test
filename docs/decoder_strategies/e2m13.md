# E2M13 strategy decision

E2M13 reserves exponent three for Inf/NaN and has bias one. U(0,1) is almost
entirely encoded through exponent zero; about 68.27% of N(0,1) magnitudes also
fall below the first normal value at 1. A generic "rare subnormal" slow path is
therefore inappropriate.

Implemented candidates:

- generic codec control;
- branchy and masked direct FP64 high-word construction with CLZ normalization;
- exact FP32-bit construction followed by FP64 conversion;
- complete 65,536-entry high-word LUT through global/L2;
- 8,192-entry, 32 KiB subnormal high-word LUT through global or shared memory;
- eight-entry, 32-byte sign/exponent prefix table through global or shared
  memory, with exponent-zero values normalized directly;
- x1/x2/x4/x8 aligned packet loads.

The subnormal table is small enough for ordinary shared-memory launches. The
prefix table removes exponent rebias work only for normal/special encodings and
is therefore less likely to help U(0,1). Local and GPU smoke validation exhaust
all 65,536 encodings and compare NaNs by class.
