# E2M5 strategy decision

E2M5 already has a dedicated 42-strategy implementation and H200 study. Those
families cover generic, FP32/FP64/high-word/prefix LUTs, global/shared tables,
direct branchy/masked words, subnormal hybrids, bank-swizzled tables, and
x1/x2/x4/x8 packets.

This pass adds the remaining credible packet strategy:

- a 65,536-entry, 512 KiB global/L2 pair table returning two FP64 high words
  per lookup, tested at x4/x8;
- byte-permute extraction for the direct branchy x4/x8 path in the common
  strategy framework.

The pair table is not staged into shared memory. E2M5's exponent-zero path is
hot for essentially all U(0,1) and about 68.27% of N(0,1), so the existing
LP-S x8 and subnormal-focused strategies remain the targets to beat. All 256
codes are exhaustively validated locally and in the cumulative GPU smoke run.
