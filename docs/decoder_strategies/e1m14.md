# E1M14 strategy decision

Finite E1M14 is a signed fixed-point grid with exact magnitude
`K * 2^-13`. U(0,1) uses the exponent-zero field almost exclusively, and about
95.45% of N(0,1) magnitudes are below the first normal encoding at 2.

Implemented candidates:

- generic codec control;
- fixed-point integer-to-FP64 plus exact `2^-13` scale;
- branchy and masked direct FP64 high-word construction;
- exact FP32-bit construction followed by FP64 conversion;
- complete 65,536-entry high-word LUT through global/L2;
- 16,384-entry subnormal high-word LUT through global memory;
- the same 64 KiB subnormal table staged in shared memory;
- x1/x2/x4/x8 aligned packet loads.

The complete table is 256 KiB and cannot fit in one Hopper block's shared
memory. The subnormal table does fit but needs dynamic-shared-memory opt-in.
Shared staging is expected to be more defensible for long DOT loops than for
one-block-per-row GEMV. Local validation exhausts all 65,536 encodings.
