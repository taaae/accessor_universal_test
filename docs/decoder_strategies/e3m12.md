# E3M12 strategy decision

E3M12 reserves exponent seven for Inf/NaN and has bias three. Its first normal
magnitude is 0.25, so source subnormals account for 25% of U(0,1) and about
19.74% of N(0,1), substantially less than E2M13.

Implemented candidates:

- generic codec control;
- branchy and masked direct FP64 high-word construction;
- exact FP32-bit construction followed by FP64 conversion;
- complete 65,536-entry high-word LUT through global/L2;
- 4,096-entry, 16 KiB subnormal high-word LUT through global or shared memory;
- 16-entry sign/exponent prefix table through global or shared memory, with
  exponent-zero values normalized directly;
- x1/x2/x4/x8 aligned packet loads.

The smaller and colder subnormal table may rank differently from E2M13. The
prefix path is also more credible because most values use a regular exponent.
Local and GPU smoke validation exhaust all 65,536 encodings.
